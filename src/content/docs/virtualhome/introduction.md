VirtualHome is a standalone, simulation-first digital twin for exploring household routines and automation behavior.

## Goals

- Model a household as an understandable set of rooms, devices, people, and events.
- Make every simulation transition observable and reproducible.
- Keep the core useful without requiring an external home-automation platform.

## What this documentation covers

The pages in this section describe how to run the project, how the runtime is divided, how state changes move through the simulation, and how external callers interact with it.
